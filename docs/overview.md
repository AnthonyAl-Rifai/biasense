# BiaSense Extension: Overview

This Chrome extension detects logical fallacies, rhetorical bias, and opinion-based statements in web articles.
It overlays color-coded highlights on text and offers contextual tooltips.

## Tech Stack
- React + TypeScript (Chrome Extension)
- Node.js (Express) + TypeScript (Backend)
- Claude or OpenAI (AI model)
- SCSS with BEM
- ESLint + Prettier
