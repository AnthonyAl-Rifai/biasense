# AI Prompting Strategy

## Prompt Instructions
1. Read the paragraph for context.
2. Highlight:
   - Logical fallacies (name + subtype)
   - Biased or emotionally charged language
   - Subjective opinions stated as facts
3. Return:
   - Matched text
   - Category + subtype
   - Explanation
   - Severity (0.0 to 1.0)

## Goals
- Avoid over-flagging neutral/satirical content
- Maintain contextual accuracy (not sentence-only)
